01 / FUNDAMENTALS

What an API actually does

A frontend asks for data or requests a change. The API receives the HTTP request, runs server code, and sends back a response with a status code and often JSON.

ClientClicks “View result”
HTTP request →
FastAPIMatches a route and runs Python
JSON response →
ClientDisplays the result

HTTP methods express intent

GETRead a studentPOSTCreate a studentPUTReplace editable fieldsPATCHChange selected fieldsDELETERemove a student

Your first endpoint

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home() -> dict[str, str]:
    return {"message": "Welcome to FastAPI"}

@app.get("/") registers a GET route. The function runs for a matching request; FastAPI serializes the returned dictionary as JSON. A return annotation describes the value but does not return it.

Why use a decorator?

At import time, the decorator registers a relationship between an HTTP method, a URL path, and your function. When a request arrives, FastAPI uses that registration to choose which function to call.

03 / PATH PARAMETERS

From a URL to a Python argument

A path value identifies a specific resource. FastAPI takes the text from the URL, validates it against the annotation, and passes the converted value to your function.

Read a function signature

def add(a: int, b: int) -> int:
    return a + b

answer = add(5, 3)  # 8

a and b are parameters; 5 and 3 are arguments. : int and -> int are type hints. Only return sends a value back.

Bind a path value

@app.get("/students/{student_id}")
def get_student(student_id: int):
    if student_id not in students:
        raise HTTPException(404, "Student not found")
    return students[student_id]

For GET /students/2, FastAPI calls get_student(student_id=2). The placeholder and function parameter must share the name.

GET /students/abc422 · “abc” cannot be parsed as an integer. The function does not run.
GET /students/999404 · The integer is valid, but your code cannot find that record.
What about route order?

Declare a fixed route such as /students/all before /students/{student_id}. Otherwise the dynamic route may match “all” first and produce a validation error. A path such as /students/2/courses/5 can bind both student_id and course_id.

04 / QUERY PARAMETERS

Identify, filter, and page

The path usually identifies a resource. The query string often adjusts how you read it: search, filter, sort, or paginate.

GET/students/5?include_courses=true
5 → path: which student?include_courses → query: what extra data?
REQUIRED
def search(name: str):

/search → 422
/search?name=Ali → “Ali”

DEFAULT
def list_students(limit: int = 10):

Without limit, the value is 10. With ?limit=5, it is 5.

OPTIONAL
def list_students(name: str | None = None):

The = None default makes omission possible. The union type alone does not.

How FastAPI decides

@app.get("/students/{student_id}")
def read(student_id: int,
         details: bool = False): ...

student_id appears in the path template. The other scalar parameter, details, comes from the query string. A Pydantic model parameter is normally read from the JSON body.

Pagination is a slice

result = students[skip : skip + limit]

?skip=2&limit=2 selects the third and fourth items. The optional example constrains skip ≥ 0 and 1 ≤ limit ≤ 100. Slicing a list is illustrative; a database should page in its query.

VISUAL WALKTHROUGH

Where does each value come from—and where does it go?

The decorator is a matching rule registered when Python imports the file. Later, the client sends an actual request. FastAPI connects its values to function parameters before calling your code.

Read the three places: /students/{student_id} is the route pattern; /students/2 is the client's URL; student_id: int is the function parameter that receives 2.

01 · CLIENT SENDSGET /students/2

The browser sends a GET request to this actual URL.

02 · FASTAPI MATCHES@app.get("/students/{student_id}")

GET must match GET; {student_id} is a named slot for one path segment.

03 · FUNCTION RECEIVESdef get_student(student_id: int):

FastAPI converts URL text "2" to integer 2 and calls get_student(student_id=2).

04 · YOUR CODE RUNSstudents[2] → Sara

The function reads a record from the dictionary. FastAPI did not look up the student for you.

05 · CLIENT RECEIVES200 {"id":2,"name":"Sara","age":22}

The returned dictionary becomes a JSON response.

The bridge: {student_id} in the path pattern has the same name as student_id in the function. The function name get_student does not determine the URL.

These examples assume the initial Ali and Sara records. Reset the lab if you previously changed its data.

GET/studentsList, search, filter, page200
GET/students/{student_id}Read one; missing ID → 404200
POST/studentsCreate with validated body201
PUT/students/{student_id}Replace name and age200
PATCH/students/{student_id}Update supplied fields only200
DELETE/students/{student_id}Remove; empty response body204

PUT: complete editable state

PUT /students/1
{"name":"Ali Khan","age":21}

Both fields are required. The URL ID stays the same. Our example returns 404 if the student does not exist; some other APIs choose to create on PUT.

PATCH: supplied fields only

PATCH /students/1
{"age":23}

model_dump(exclude_unset=True) keeps only fields sent by the client. The API rejects explicit null because name and age cannot be null in the stored student.

Why use Pydantic models?

StudentIn describes the create and replace body; StudentPatch allows omitted fields; StudentOut describes responses. FastAPI validates incoming data and generates OpenAPI documentation from these models. Python type hints by themselves do not validate ordinary function calls.

What are the important status codes?

200 successful read or update; 201 created; 204 success with no body; 400 application-defined bad request; 401 authentication required; 403 forbidden; 404 record missing; 422 validation failure; 500 unexpected server failure. Status codes describe the result; a return value alone does not save data.

Optional: reveal a complete runnable example

Copy this into main.py if you want to compare the browser lab with real FastAPI responses. It stores data in memory and resets on restart.

from fastapi import FastAPI, HTTPException, Query
from pydantic import BaseModel, Field

app = FastAPI()

class StudentIn(BaseModel):
    name: str = Field(min_length=1)
    age: int = Field(ge=0)

class StudentPatch(BaseModel):
    name: str | None = Field(default=None, min_length=1)
    age: int | None = Field(default=None, ge=0)

students = {
    1: {"id": 1, "name": "Ali", "age": 20},
    2: {"id": 2, "name": "Sara", "age": 22},
}
next_id = 3

def find_student(student_id: int):
    if student_id not in students:
        raise HTTPException(404, "Student not found")
    return students[student_id]

@app.get("/students")
def get_students(
    search: str | None = None,
    min_age: int | None = Query(default=None, ge=0),
    skip: int = Query(default=0, ge=0),
    limit: int = Query(default=10, ge=1, le=100),
):
    result = list(students.values())
    if search is not None:
        result = [s for s in result
                  if search.casefold() in s["name"].casefold()]
    if min_age is not None:
        result = [s for s in result if s["age"] >= min_age]
    return result[skip:skip + limit]

@app.get("/students/{student_id}")
def get_student(student_id: int):
    return find_student(student_id)

@app.post("/students", status_code=201)
def create_student(student: StudentIn):
    global next_id
    created = {"id": next_id, **student.model_dump()}
    students[next_id] = created
    next_id += 1
    return created

@app.put("/students/{student_id}")
def replace_student(student_id: int, student: StudentIn):
    find_student(student_id)
    students[student_id] = {"id": student_id, **student.model_dump()}
    return students[student_id]

@app.patch("/students/{student_id}")
def update_student(student_id: int, changes: StudentPatch):
    current = find_student(student_id)
    updates = changes.model_dump(exclude_unset=True)
    if any(value is None for value in updates.values()):
        raise HTTPException(422, "name and age cannot be null")
    current.update(updates)
    return current

@app.delete("/students/{student_id}", status_code=204)
def delete_student(student_id: int):
    find_student(student_id)
    del students[student_id]
    return None

find_student centralizes the 404 rule. Query constrains pagination. exclude_unset=True distinguishes omitted PATCH fields from fields explicitly sent as null. global next_id only updates this teaching example’s counter; a real database would generate IDs.

    Quick revision
    Path identifies a resource; query adjusts a request; body sends structured data. FastAPI validates incoming values, while your code decides what to read or change. PUT replaces the complete editable state; PATCH applies supplied fields. A valid ID type can still point to a missing record.
